CBRE Claude Setup Guide

Your CBRE Claude Morning Brief

A practical, end-to-end walkthrough of getting a daily AI-generated briefing from your CBRE Claude app. Two modes, same app: the 5-minute manual setup using standard chat, or the fully automated version with Cowork enabled for scheduling.

10 min read Updated for Claude 4.x and Cowork Tested on Mac and Windows
01 · Reality Check

Why Claude won't send the email (yet)

The most common stumbling block. It is not a plan tier issue, and upgrading will not fix it. Here is what is actually happening.

What you've been told

  • You need the $2,600 advanced plan to unlock email sending
  • The M365 connector permissions just need to be changed
  • This is a license or seat-level restriction

What's actually happening

  • The M365 connector is read and search only by design
  • No send_email tool exists in the connector to enable
  • Plan tier does not change which tools a connector exposes
  • This is a Microsoft connector capability question, not an Anthropic plan question
The 7 tools your M365 connector exposes today
All read-only · No write capability
Routlook_email_search
Routlook_calendar_search
Rsharepoint_search
Rsharepoint_folder_search
Rchat_message_search
Rfind_meeting_availability
Rread_resource
✕send_email (missing)
→
Bottom line: Toggling permissions to "Always allow" does not add tools that aren't there. The plan upgrade does not change connector capabilities. The two real solutions are below.
02 · Two Modes, One App

Pick your level of automation

CBRE Claude is the app already installed on your work computer (Windows or Mac, deployed by CBRE IT). You can use it two ways. Both are inside the same app. The difference is whether you enable Cowork for automation.

Before we start: two modes of the same app

Most people on day one think "Cowork" is a separate product they need to install. It isn't. Cowork is a feature inside CBRE Claude that you turn on. The chat interface is what you're already using. Both modes run in the same app, on the same machine, with the same login.

CBRE Claude · Standard Chat (no Cowork needed) 03 · Path 1

Manual brief in standard chat

Everything in this path happens inside the CBRE Claude app you already have on your work computer, using standard chat. Nothing extra to install or enable. 5 minutes to set up. Run it each morning in about 2 minutes.

1

Open CBRE Claude on your work computer

Launch the CBRE Claude app from your Start menu (Windows) or Applications folder (Mac). Sign in with your CBRE credentials if you aren't already. You'll land on the main chat interface.

If you don't see Claude installed: Submit a ticket to CBRE IT to get it deployed to your machine. It's part of the standard Claude Enterprise rollout. Most CBRE laptops already have it.
2

Create a dedicated Morning Brief project

In the left sidebar, click Projects, then + New Project. Name it "Morning Brief" or similar. Projects isolate context, save custom instructions, and let you upload reference files (like your listing tracker).

Why this matters: Without a dedicated project, you re-explain who you are, what listings you cover, and what format you want every single morning. The project eliminates that.
3

Add project instructions with your context

Inside the new project, find Project Settings → Custom Instructions. Paste a structured template covering your role, team, active deals, and brief preferences.

# MORNING BRIEF CONTEXT Role: [Your title], CBRE [Your Practice], [Your Market] Team: [Manager], [Direct reports], [Coordinator] Active Listings (priority order): 1. [Address] | [Owner], [SF], [status] 2. [Address] | [Owner], [SF], [status] 3. ... Active Tenant Rep Clients: 1. [Client] | [Size], [Submarket], [Stage] 2. ... Brief Format Preferences: - No em dashes - Bullets and headers, not prose walls - Lead with the answer - Use native CRE terminology (NNN, FSG, TI, NER, LOI) - One screen max
4

Verify your M365 connector is connected

Go to Settings → Connectors. Confirm Microsoft 365 shows as connected and all 7 read tools are enabled. Set tool permissions to Always allow to skip approval prompts. (Reminder: this does not add a send tool, but it speeds up daily runs.)

5

Use a structured morning prompt

Save this as a reusable prompt. Paste it into the Morning Brief project each morning.

Generate my morning brief for today. Search my Outlook inbox for any flagged or urgent messages from the last 24 hours. Pull my calendar for today. Cross reference the two and flag connections (e.g., a tour with a tenant rep who emailed yesterday). Then run a web search for new VC funding rounds in Bay Area life science and AI from the last 7 days, Series A through C. Structure: 1. Top of the Day (1 sentence anchor) 2. Critical (deadlines, deals at risk, urgent replies needed) 3. Today's Calendar (with prep notes per meeting) 4. Active Deal Status Changes 5. Market Intel (funding rounds, new listings, comps) 6. Action Items (3-5 max, ordered by priority) Keep it scannable in 60 seconds. No em dashes.
6

Send it to yourself with one click

After Claude generates the brief, type: "Draft this as an email to me." Claude uses its built-in message compose tool, which produces the email with an Open in Mail button. Click it. The whole brief lands in a composed Outlook message. Review, send, done.

Why this beats waiting for native send: You retain editorial control, the email is sent from your actual Outlook (correct signature, correct sent folder), and there is no IT involvement.
7

(Optional) Archive each brief in a synced folder

Standard chat briefs live in your Claude chat history. To create a searchable archive (useful for going back to find "when did we first hear about this prospect?"), save each one as a markdown file.

  • After the brief is generated, copy the content
  • Save as a new file: 2026-05-15-brief.md
  • Drop it in a synced folder: OneDrive Personal/Morning Briefs/ or a SharePoint library
  • Use the same folder structure as Path 2 below: Year/Month/file.md
Worth the 10 seconds: After a few months you have a date-stamped archive that's fully searchable. "What did we discuss about this prospect last quarter?" becomes a 5-second answer instead of a 30-minute Outlook dig.
CBRE Claude · Cowork Enabled (automation features on) 04 · Path 2

Automated brief with Cowork

Same CBRE Claude app as Path 1. The difference is that Cowork is enabled, which unlocks scheduling and file output. The schedule runs the brief on its own and writes it to a folder. Mine triggers at 7:30am every weekday and is waiting before I open the laptop.

Same app, different mode: Path 1 used the standard chat interface inside CBRE Claude. Path 2 uses the same CBRE Claude app but with Cowork features turned on. You don't install anything new. Cowork is a feature flag inside the app you already have.
1

Confirm Cowork is enabled in your CBRE Claude

Open CBRE Claude on your work computer (same app as Path 1). Go to Settings → Cowork. Confirm it's enabled. Cowork is part of the standard CBRE Claude deployment.

Hardware: Cowork only runs on the machine where CBRE Claude is installed. For unattended daily runs (the brief at 7:30am whether or not you're at your desk), dedicate a small machine (Mac Mini, NUC, or a spare laptop in a drawer) plugged in and set to never sleep. Your daily-driver laptop closing for the day will not run the task.
2

Choose where the brief will be saved

Cowork writes the brief as a file to a folder on your machine. Two options based on your environment. Pick one before building the skill.

Option A OneDrive personal
For solo workflows, mobile access via OneDrive app

Use when:

  • You work mostly solo and don't need team visibility
  • You want the brief accessible on your phone via the OneDrive mobile app
  • You already have OneDrive sync configured and working
The CBRE gotcha to avoid: CBRE Group Policy applies Known Folder Move, which redirects your Documents folder into OneDrive. This makes the OS see Documents as a different device than your C: drive. Cowork scheduled tasks writing to Documents/Morning Briefs/ can fail silently with EXDEV (cross-device link) errors. The task appears to run but no file ever appears. This is the single most common Cowork setup failure in CBRE environments.

The fix: Don't use the Documents path. Use the explicit OneDrive path:

Windows
C:\Users\[username]\OneDrive - CBRE\Morning Briefs\
Mac
/Users/[username]/Library/CloudStorage/OneDrive-CBRE/Morning Briefs/
Test before scheduling: Run the skill manually once. Verify the file appears in BOTH File Explorer/Finder AND OneDrive web. If it appears in one but not the other, you have a sync issue to fix before scheduling.
Recommended for CBRE Option B
SharePoint Teams site

Use when:

  • Team visibility of briefs is desirable (associate or coordinator can reference)
  • You want the most reliable option in CBRE Group Policy environments
  • You're in an environment where OneDrive Known Folder Move has caused issues before
Step Zero (people miss this and the whole setup breaks): Before Cowork can write to SharePoint, you must sync the document library to File Explorer. SharePoint URLs are not writable filesystem paths.

Step Zero setup:

  • Open the SharePoint site in browser
  • Navigate to the document library (usually called "Documents")
  • Click the Sync button at the top of the library
  • Approve the OneDrive prompt that pops up
  • Wait 30 seconds for the library to appear in File Explorer / Finder
  • Verify the SharePoint library shows under your name with a SharePoint icon

After Step Zero, paths look like:

Windows
C:\Users\[username]\CBRE\[Team Site Name] - Documents\Morning Briefs\
Mac
/Users/[username]/Library/CloudStorage/OneDrive-SharedLibraries-CBRE/[Team Site Name] - Documents/Morning Briefs/

Recommended folder structure (either option):

Morning Briefs/ 2026/ 05-May/ 2026-05-15-brief.md 2026-05-16-brief.md 2026-05-17-brief.md
3

Build your morning brief skill

Skills are reusable workflows defined in a SKILL.md file. Create one called morning-briefing that captures structure, data sources, and output format. Cowork follows it every time the skill is triggered.

name: morning-briefing description: Generates the daily CRE morning briefing and writes to disk. triggers: - phrase: "morning brief" - schedule: "weekdays 7:30am" inputs: - calendar: Outlook calendar via M365 connector - inbox: Outlook flagged/urgent emails, last 24h - market_data: web search for VC funding + new listings workflow: 1. Pull today's calendar 2. Pull flagged inbox items from last 24h 3. Cross-reference calendar against inbox 4. Web search: Bay Area VC funding, last 7 days 5. Web search: new listings in target submarkets 6. Compose structured brief 7. Write output to configured path output: format: markdown filename_pattern: "YYYY-MM-DD-brief.md" path: [your OneDrive or SharePoint path from Step 2] format_rules: - No em dashes or en dashes - Bullets and short headers - Native CRE terminology - One-screen length - Structure: Top of Day | Critical | Calendar | Market Intel | Action Items
Customize freely: Add your active listings, tenant rep clients, team names, and prospecting target profile directly into the skill so the brief is grounded in your book without re-explaining context every day.
4

Schedule the task

Two paths depending on your OS. Cowork's built-in scheduler is easiest where available. Native OS schedulers work as fallback.

Mac
Cowork built-in scheduler (easiest)
  • Open CBRE Claude, navigate to Cowork settings
  • Scheduled Tasks → Add
  • Trigger: 7:30 AM, Monday through Friday
  • Action: Run skill morning-briefing
  • Machine must be awake at trigger time. For unattended operation: dedicated Mac Mini, plugged in, set to never sleep, auto-login enabled.

Alternative: LaunchAgent in ~/Library/LaunchAgents/ for more flexibility, but Cowork scheduler is simpler if it works for your trigger needs.

Windows
Task Scheduler (built into Windows)
  • Open Task Scheduler from Start menu
  • Create Basic Task → Name it "Morning Brief"
  • Trigger: Weekly, Mon-Fri, 7:30 AM
  • Action: Start a program → point to CBRE Claude executable with skill invocation argument
  • Settings tab: check "Run whether user is logged on or not" AND "Wake the computer to run this task"
  • Machine must be plugged in. Battery-powered laptops will not wake to run scheduled tasks by default.
My setup: Mac Mini in the home office, plugged in 24/7, set to never sleep, Cowork running scheduled task at 7:30am every weekday. Brief drops into OneDrive/Morning Briefs/ with the date in the filename. I open it on my phone with coffee, then again on my laptop when I sit down. Zero manual work to generate it.
5

Test before going live

Before you trust the schedule, prove the skill works end-to-end:

  • Run the skill manually from Cowork (don't wait for the schedule)
  • Verify the file appears in your File Explorer / Finder at the expected path
  • Open OneDrive web (or SharePoint web) and confirm the file synced up
  • Open the file and confirm the content matches your expected format
  • If everything passed: enable the schedule. Tomorrow morning, the brief appears on its own.
Don't skip testing. The most common failure mode is the scheduled task running successfully but writing nowhere (silent EXDEV error). You'll only catch this if you test manually first.
6

(Optional) Configure Outlook OAuth for auto-send

To skip the "Open in Mail" step entirely and have Cowork place the email directly in your outbox, you need Outlook OAuth and an Azure app registration. This is enterprise IT work, not user-side configuration.

Reality check: This requires a CBRE IT ticket. Expect timelines measured in weeks, not days. Until then, Cowork can still drop the brief as a file to your synced folder, which gives you 90% of the value. The file is just as useful as the email for most workflows.

06 · Pro Tips

Things that materially improve the brief

Patterns I've learned the hard way over a year of running this every morning.

TIP 01
Cross-reference is everything

The brief that catches "you have a 2pm tour and the tenant rep emailed last night" is 10x more valuable than two separate lists of meetings and emails.

TIP 02
Constrain to one screen

If your brief takes more than 60 seconds to read, you'll stop reading it. Cap it at 6 sections, 3-5 items each. Force prioritization.

TIP 03
VC funding feeds prospecting

A weekly funding round scan in your tenant target profile (sector, stage, geography) is the best prospecting trigger in life science and AI.

TIP 04
Use a consistent structure

Same sections, same order, every day. Your brain stops reading and starts scanning. That's the goal: you should be done with it before your second sip of coffee.

TIP 05
Iterate the prompt weekly

Every Friday, ask Claude: "What did I miss this week that should have been in the brief?" Use those gaps to refine the prompt.

TIP 06
Save your briefs

A folder of date-stamped briefs becomes a searchable archive. "When did we first hear about that prospect?" becomes a 10-second search.

TIP 07
Build a feedback loop

End each brief with: "Anything off-base or missing?" Tell Claude, then update the project instructions. The brief gets sharper every week.

TIP 08
Don't share confidential context broadly

Active deal economics, tenant identities, and pricing live in the project. Don't paste them into web searches or external API calls.

07 · Troubleshooting

Common failure modes and fixes

When something stops working, it is almost always one of these. Listed in order of how often each comes up.

1
EXDEV error: brief generates but no file appears (OneDrive)
Fix: You're writing to Documents/Morning Briefs/ through the Known Folder Move layer. Change the output path to the explicit OneDrive path: OneDrive - CBRE\Morning Briefs\ on Windows or ~/Library/CloudStorage/OneDrive-CBRE/Morning Briefs/ on Mac.
2
SharePoint output path returns "not found" or write error
Fix: You skipped Step Zero. Open the SharePoint site in your browser, click the Sync button at the top of the library, approve the OneDrive prompt, wait 30 seconds. The library will appear in File Explorer / Finder. Now Cowork can write to that local path.
3
Brief appears but content is empty or sparse
Fix: M365 connector has likely lost authentication. Open Claude Desktop, go to settings, find the M365 connector, click reauthorize. Sign in again with your CBRE credentials. Re-run the skill manually to verify before trusting the schedule again.
4
Scheduled task fires at 7:30am but no brief generated
Fix: Machine was asleep. On Windows, enable "Wake the computer to run this task" in Task Scheduler settings and confirm machine is plugged in. On Mac, use a machine set to never sleep, or wake it manually. Battery-powered laptops on battery will not wake for scheduled tasks by default.
5
Schedule fires but Cowork can't find the skill
Fix: Cowork skills are account-wide, not project-scoped. Open Cowork, confirm the morning-briefing skill is installed at the account level (not just inside a specific project). Reinstall if needed.
6
Brief generates but quality is inconsistent day to day
Fix: The skill prompt or project instructions are too vague. Add concrete examples of what "Critical" vs "Pro tip" looks like for you. Specify exactly which submarkets to scan, which sectors qualify as prospect signals, and what format violations to avoid (em dashes, prose walls, etc.). The more specific the rules, the more consistent the output.
7
M365 connector says "always allow" but Claude still asks every time
Fix: The toggle did not save. Re-open settings, set each individual tool permission (outlook_email_search, outlook_calendar_search, etc.) to Always allow one by one, then close and re-open Claude Desktop.
8
Setup works for one week, then suddenly stops
Fix: Most likely an OS update broke the scheduled task, or the Claude Desktop app updated and reset settings. Open the scheduler, confirm the task is still enabled. Open Claude Desktop, confirm Cowork is still enabled and the skill is still installed. Re-run manually to verify.
